# Security Policy

Windows-Process-Injector-C is intentionally preserved as a compact **legacy WinAPI research PoC** for controlled labs and detection-oriented study.

## Project status

This repository is not an actively expanded injector framework. The intentionally simple implementation documents a classic remote-thread injection primitive and its observable Windows behavior.

## Reporting issues

For documentation problems, build problems, unsafe defaults, or other repository-level issues, open a GitHub issue.

If a report contains sensitive information, use GitHub's private vulnerability-reporting / security-advisory flow when available. Do not publish credentials, private infrastructure details, or third-party data in an issue.

## Out of scope

Requests to add stealth, EDR bypasses, persistence, credential access, privilege escalation, payload generation, target discovery, evasion, or remote-control capability are outside the purpose of this repository.

## Safe use

Run the sample only in an isolated lab environment against disposable processes and systems you own or are explicitly authorized to test.
