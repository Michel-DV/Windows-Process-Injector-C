# Security Policy

## Scope

This repository is an educational Windows process-injection research lab. It exists to support malware analysis, detection engineering, reverse engineering, and controlled security testing.

## Responsible use

Only use the project on systems you own or have explicit authorization to test. Prefer disposable virtual machines and isolated lab environments.

Do not use the repository to target third-party systems, evade security controls, establish persistence, obtain credentials, or deploy payloads outside an authorized research environment.

## Reporting a security issue

If you find an unintended vulnerability in the repository itself, avoid publishing sensitive exploitation details in a public issue. Use GitHub's private vulnerability reporting feature when available.

## Project boundaries

The repository intentionally does not aim to provide stealth, bypass, persistence, privilege escalation, command-and-control, credential access, or operational malware functionality.
